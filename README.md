#  Disaster Prep App

A lightweight, web-based interactive application designed to help users prepare for, respond to, and stay safe during natural disasters and emergency situations.

##  Features

- **Emergency Preparedness Checklists:** Step-by-step guidance on essential supplies, medical kits, and document backups.
- **Action Guides:** Specific instructions for various emergency scenarios (e.g., earthquakes, floods, fires, severe storms).
- **Interactive UI:** Simple, responsive HTML/CSS interface accessible across mobile and desktop devices.
- **Offline Access:** Designed as a single-page app for fast loading and low bandwidth usage during emergencies.

##  Built With

- **HTML5** - Page structure and semantic layout
- **CSS3** - Styling and responsive design
- **JavaScript (Vanilla)** - Interactive elements and dynamic state management
